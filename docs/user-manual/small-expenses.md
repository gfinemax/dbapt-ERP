# 소액지출 확인·확정

경로: 기안·결재 → 소액결의 (`/approval/small-expense`).

사무국장이 등록하고 조합장이 사용내용·영수증을 확인해 선택 확정한다. 건별 기안이나 월별 지출결의서를 다시 생성하지 않는다. 확정은 내부규정에 따라 지정된 확인자의 처리이며, 감사상 무조건적인 비용 인정을 의미하지 않는다.

## 적용과 계정

`20260906234558_small_expense_chair_confirmation.sql` 적용 후 앱을 배포한다. 마이그레이션은 기존 일괄결의 연결을 보존하고 새 batch RPC 실행을 차단한다. 기존 미연결 내역은 등록자·사용자·예산·증빙을 보완한 후 확인한다. 조직이 없는 과거 내역을 임의로 현재 조직에 배정하지 않는다.

개인 지출 정산과 같은 로그인 계정을 사용한다. 그 화면의 계정·권한 관리에서 활성 계정을 준비한 뒤, 관리자가 소액 화면의 ‘소액지출 담당자 지정’에서 서로 다른 사무국장·조합장 계정을 지정하고 근거를 남긴다. 관리자라는 이유만으로 소액지출을 확정할 수는 없다. 기존 계정을 자동으로 조합장에 지정하지 않는다.

## 등록과 확인

1. 사용월을 선택한다. 사무국장이 실제 사용자, 사용내용, 금액, 결제수단과 증빙을 등록한다. 계정과목과 일치하는 예산항목이 하나면 자동 선택하며 직접 수정할 수 있다.
2. 조합 현금은 영수증을 첨부한다. 조합 통장·법인카드는 같은 사용일·금액의 실제 거래를 연결하고 영수증도 첨부한다. PDF/PNG/JPEG/WebP 3MB 이하를 지원한다. 다른 지출과 중복 연결되는 거래는 서버에서 차단한다.
3. 개인 돈으로 결제한 비용은 기존 개인 지출 정산에서 신청한다. 소액지출로 중복 등록하지 않는다.
4. 등록 내역은 ‘조합장 확인대기’가 된다. 거래처 미확인은 등록 가능하지만 확정 전 보완해야 한다.
5. 조합장은 상세내역과 영수증을 열어 확인하고, 확인 체크 후 여러 건을 선택 확정한다. 본인이 등록하거나 사용한 건은 확정·보완 검토할 수 없다. 해당 건은 내부규정에 따른 다른 확인 절차가 필요하다.
6. 보완 요청에는 사유가 필요하다. 사무국장이 수정 후 재등록하면 확인대기로 돌아간다. 잘못 등록한 미확정 내역은 사유를 남겨 취소할 수 있다.

한 건이라도 권한·버전·예산·증빙 검증에 실패하면 그 선택 작업 전체를 롤백한다. 이미 확정된 내역은 다시 확정하거나 일반 간편지출 화면에서 수정·전환할 수 없다. 확정 취소·환급은 이 화면의 등록 취소 기능에 포함되지 않으며, 별도의 승인된 정정 절차가 필요하다.

## 예산과 월별 집계

확정할 때 기존 간편지출 예산 원본을 한 번 생성한다. 월·연간 잔액 및 마감 검증은 통합 예산 로직을 적용한다. 확정자·시각·당시 한도를 보존한다. 소액지출 원본과 예산 원본을 두 번 합산하지 않는다. 전표를 생성하거나 실제 은행 송금을 실행하는 기능은 아니다.

소액 화면은 조회 월의 확정 내역을 계정과목별로 집계한다. 미확정·보완·취소·기존 일괄결의 연결은 확정 합계에 포함하지 않는다. 확인대기·보완 내역이 있으면 통합 월 마감을 차단한다. 마감된 월에는 새 소액 등록·확정을 허용하지 않는다. 예산 귀속 확인이나 월 예산 부족은 통합 예산 화면에서 먼저 해결한다.

처리 이력은 등록·수정 전후 값, 처리자, 시각, 사유를 저장하며 수정·삭제할 수 없다. 화면에는 최근 50건을 표시한다. 증빙은 권한 검사 후 60초 유효 링크로 열람한다.
