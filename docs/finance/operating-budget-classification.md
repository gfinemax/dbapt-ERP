# 2026 조합 운영비 예산·지출 세부항목 연결

## 관리 원칙

- 승인 예산안 22개 항목과 월·연간 금액을 예산 원장으로 사용한다.
- 지출 세부항목은 각각 하나의 승인 예산에 연결하며 별도 예산 금액을 갖지 않는다.
- 실제 지출은 세부항목을 선택해 저장하고 예산 사용액은 연결된 승인 예산으로 합산한다.
- 기존 지출의 문자열 예산항목은 변경하지 않는다. 신규 입력부터 안정적인 세부항목 ID를 함께 저장한다.
- 간편지출과 지출결의는 사용내용·건명·적요·거래처·영수증 OCR 품목을 같은 추천 기준으로 분석해 세부항목과 승인 예산을 자동 설정한다.
- 구체적인 분류 근거가 없거나 여러 의미로 해석되는 `기타`는 자동 선택하지 않는다. 사용자가 직접 고른 세부항목은 이후 입력이나 OCR 추천으로 덮어쓰지 않는다.
- 저장된 간편지출에 OCR 결과를 반영해 분류를 바꾸면 사용내용·거래처·세부항목·승인 예산을 한 번의 감사 가능한 처리로 저장한다.
- `정책 확인 필요` 항목은 지출결의서에서 선택할 수 있지만 예산 내 간편지출은 허용하지 않는다.

## 기존 기록 처리

기존 결의서와 간편지출은 당시 저장된 예산 문자열과 금액을 보존한다. `사무용품`이라고 적힌 과거 지출도 담당자 확인 없이 새 항목으로 옮기지 않는다. 예산 귀속 검토 화면에서 실제 증빙과 사용 목적을 확인한 뒤 필요한 건만 관리자가 재분류한다.
