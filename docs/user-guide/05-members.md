# 5. 조합원 관리 튜토리얼

## 튜토리얼: 조합원 조회와 상세 확인

1. 사이드바에서 `조합원`을 선택하거나 퀵메뉴의 `조합원 등록`을 사용한다.
2. 목록에서 조합원명, 상태와 납부 관련 정보를 확인한다.
3. 조합원을 선택해 상세 화면으로 이동한다.
4. 기본정보, 계약·분양, 분담금 납부와 최근 변경사항을 확인한다.
5. 정보가 부족하면 원본 계약서나 납부자료를 확인한 뒤 보완한다.

완료 기준: 조합원 목록과 상세의 성명, 상태와 납부 정보가 일치한다.

주의: 주민번호, 연락처, 계좌정보 등 개인정보는 업무에 필요한 범위에서만 열람하고 외부로 전달하지 않는다.
