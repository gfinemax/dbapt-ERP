# 사용설명서 변경이력

## 2026-09-20

- 실제 사용일·예산 귀속월·신청일·지급일·회계 반영일을 구분하는 지출·정산 운영기준을 추가했다.
- 법인카드, 개인 선지출, 선지급, 신탁 운영비·사업비, 긴급지출, 취소·환불과 지급거절의 공통 처리경로를 정리했다.
- 장기 지연, 마감월과 보고 완료 후 발견된 지출의 조정·중요성 검토·정정보고 판단 절차와 역할별 체크리스트를 추가했다.
- 신청기한, 금액별 승인, 회계 중요성과 과거연도 처리의 권장 초기값을 추가했다.
- 운영 기준을 나중에 변경할 수 있도록 추천값 불러오기, 영향 미리보기, 분리 승인, 시행일과 정책 버전 이력의 설정모드를 정리했다.

## 2026-07-17

- 새 기안 화면을 핵심 입력 중심으로 단순화하고 기본값, 조건부 예산·계약 영역, 회계행 자동반영, 의결 자동검토와 고급 설정을 추가했다.
- 전체 신규 기안과 지출결의서의 결재선을 `담당자 장현제 → 사무국장 오학동 → 조합장 안동연`으로 통일했다.
- 현재 운영 중인 대시보드, 기초정보, 기안·결재, 회계·지급·전표, 조합원, 인사·급여와 보고서 기준으로 최초 튜토리얼 원본을 작성했다.
- UI 변경에 대응할 수 있도록 기능별 Markdown 파일로 분리했다.
- 화면 전체 스크린샷은 UI 안정화 이후 추가하도록 이미지 관리 원칙을 마련했다.
