# 3. 기안·결재 튜토리얼

## 메뉴와 상태

- 기안 목록 `/approval`: 내 문서, 결재할 문서, 전체 문서, 작성 중, 진행 중, 승인 완료, 반려·보완, 회수·취소를 한 화면에서 확인한다.
- 새 기안 `/approval/new`: 일반기안, 지출품의, 계약기안을 작성한다.
- 소액결의 `/approval/small-expense`: 설정 한도 이하의 소액경비를 빠르게 등록한다.
- 결재 설정 `/basic-info/approval`: 예산과 의결규칙을 관리한다.

## 튜토리얼 1: 새 기안 작성

1. `기안·결재 → 새 기안`을 선택한다.
2. 일반기안, 지출품의, 계약기안 중 하나를 선택한다.
3. 제목을 입력한다. 기안 내용과 목적은 제목을 기준으로 자동 입력되며 필요한 경우에만 수정한다.
4. 금액, 대표 거래처와 첨부파일을 입력한다. 금액이 없는 일반기안은 0원으로 둘 수 있다.
5. 예산을 사용하는 문서만 `예산을 사용하는 기안`을 켜고 예산과 계정과목을 선택한다.
6. 예산을 선택하면 거래처, 예산항목, 계정과목과 총금액이 첫 회계행에 자동 반영된다. 여러 내역으로 나눌 때만 `세부내역 나누기`를 연다.
7. 계약기안을 선택하면 계약기간과 지급조건이 표시된다. 분할 지급을 켠 경우에만 지급일정을 입력한다.
8. 자동 설정에서 기안자 `오학동`, 부서 `사무국`, 오늘 날짜, 공개·보안 `내부`, 의결 `자동 검토 중`을 확인한다.
9. 프로젝트, 관련 문서, 기대효과, 증빙 종류 등은 필요한 경우에만 `고급 설정 열기`에서 수정한다.
10. 공통 결재선 `담당자 장현제 → 사무국장 오학동 → 조합장 안동연`을 확인한다.
11. 작성 도중에는 임시저장하고, 필수 금액과 세부 합계를 확인한 뒤 결재 요청한다.

완료 기준: 기안 상세에 문서번호가 생성되고 결재·의결·집행 상태가 각각 표시된다.

주의: 첨부파일 분석값은 기존 사용자 입력을 자동으로 덮어쓰지 않는다. 의결기관은 작성 단계에서 자동 검토하고, 의결이 필요한 문서는 실제 집행 전에 최종 확인한다.

## 튜토리얼 2: 결재 처리

1. `/approval`에서 `결재할 문서`를 선택한다.
2. 문서번호를 눌러 상세로 이동한다.
3. 기안내용, 예산·회계, 회의·의결, 계약·지급과 첨부파일을 검토한다.
4. 현재 결재 처리 영역에서 처리자와 의견을 확인한다.
5. 문제가 없으면 `승인`, 수정이 필요하면 사유를 입력하고 `반려`한다.
6. 다음 결재자가 있으면 상태가 결재중으로 바뀌며, 최종 승인 후 예산이 집행예정액으로 예약된다.

## 튜토리얼 3: 의결이 필요한 계약기안

1. 계약기안 작성 시 계약기간, 지급조건과 분할지급 일정을 입력한다.
2. 내부결재가 완료되어도 의결상태가 승인되기 전에는 계약·집행을 진행하지 않는다.
3. 기안 상세의 회의·의결 영역에서 추천기관과 근거를 확인한다.
4. `안건 생성`으로 이사회·대의원회·총회 안건을 연결한다.
5. 회의일자, 회차, 안건번호, 가결·부결·보류와 부대조건을 등록한다.
6. 가결 후 계약을 연결한다.
7. 분할지급 일정별로 지출결의서를 생성하고 계약금액, 누적 지급액과 잔액을 확인한다.

## 튜토리얼 4: 소액경비 일괄 처리

1. `/approval/small-expense`에서 사용일, 거래처, 사용내용, 프로젝트, 계정과목, 금액, 지급자와 비고를 입력한다.
2. 영수증 또는 PDF 증빙을 첨부한다.
3. 같은 월의 미처리 내역을 체크한다.
4. 처리자를 입력하고 `선택 월 일괄결의`를 누른다.
5. 생성된 지출결의서를 회계관리에서 검토한다.

계약 지급, 조합원 환불, 차입·상환, 소송비, 예산 외 지출과 추가부담 업무는 소액결의를 사용하지 않는다.
