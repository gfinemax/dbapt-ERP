# 2. 기초정보 준비 튜토리얼

## 튜토리얼 1: 거래처 등록 또는 수정

목적: 기안, 지출결의와 전표에서 동일한 거래처 정보를 재사용한다.

1. 사이드바에서 `회계/자금 → 기초정보 → 거래처등록`을 선택한다.
2. `거래처 추가`를 눌러 사업자 구분, 거래처명, 사업자번호, 대표자와 업태·종목을 입력한다.
3. 채권·채무 구분과 프로젝트를 실제 거래 성격에 맞게 선택한다.
4. 저장 후 목록에서 거래처명과 사업자번호를 확인한다.
5. 수정이 필요하면 해당 행의 연필 아이콘을 누르고 저장한다.

완료 기준: 새 기안의 거래처 선택 목록에서 해당 거래처를 찾을 수 있다.

## 튜토리얼 2: 계정과목 준비

1. `회계/자금 → 기초정보 → 계정과목 등록`으로 이동한다.
2. 기존 계정과목을 검색해 중복 여부를 확인한다.
3. 필요한 경우 운영비 예산안 또는 수지분석표 기준 추천 계정과목을 선택한다.
4. 코드, 계정과목명, 분류를 확인하고 저장한다.

완료 기준: 기안 세부항목과 지출결의서에서 계정과목을 선택할 수 있다.

## 튜토리얼 3: 결재·예산 설정

경로: `/basic-info/approval`

1. 의결 검토 기준금액과 소액결의 한도를 확인한다.
2. 회계연도, 예산 항목, 편성예산과 실제 집행액을 등록한다.
3. 의결기관 추천 규칙에 규칙명, 키워드, 추천 기관, 사유와 규약 근거를 입력한다.
4. 결재선 규칙에 문서유형, 최소·최대금액, 역할과 직위를 순서대로 입력한다.
5. 저장 후 등록된 예산·의결규칙·결재선 목록에서 결과를 확인한다.

주의: 결재선은 특정 사람 이름보다 역할과 직위를 기준으로 관리한다. 운영 DB에 시험용 예산이나 사용자를 넣지 않는다.
