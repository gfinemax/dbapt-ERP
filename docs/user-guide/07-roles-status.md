# 7. 역할별 업무와 상태 이해하기

## 역할별 우선 업무

- 기안자: 내 기안, 보완요청, 반려 문서와 회수 여부를 확인한다.
- 결재자·사무국: 결재대기, 의결 필요와 집행예정 문서를 확인한다.
- 조합장: 최종결재, 고액 계약, 예산 초과와 추가부담 업무를 확인한다.
- 회계담당자: 지출결의 대기, 지급예정, 증빙 누락과 전표 미생성을 확인한다.
- 감사: 예산 초과, 승인 후 변경, 취소·정정과 계약금액 초과 시도를 확인한다.

## 세 가지 상태

전자결재 상태는 작성중, 결재대기, 결재중, 승인완료, 반려, 보완요청, 회수, 취소로 관리한다.

회의 의결 상태는 대상 아님, 의결 필요, 안건 연결, 의결 완료, 부결, 보류로 관리한다.

회계·집행 상태는 미연결, 예산 예약, 집행 가능, 지출결의 초안, 지출결의 승인, 지급, 전표 생성, 종료로 관리한다.

중요: 내부결재가 승인됐더라도 의결이 필요한 문서는 의결 완료 전까지 계약과 자금집행을 진행하지 않는다.

## 대시보드 보는 순서

1. 내 결재 대기, 의결 대기, 집행 대기, 확인 필요 카드의 건수를 확인한다.
2. 긴급 또는 기한초과 건수를 먼저 처리한다.
3. 오늘의 업무에서 문서번호를 확인하고 실행 버튼으로 상세에 이동한다.
4. 예산 현황에서 실제 집행액과 승인된 집행예정액을 구분한다.
5. 주의 필요 영역의 예산 초과, 증빙 누락, 미연결 안건과 지급기한 경과를 확인한다.
