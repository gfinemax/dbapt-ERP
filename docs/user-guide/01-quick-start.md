# 1. 빠른 시작과 화면 구성

## 이 설명서의 목표

처음 사용하는 담당자가 기초정보를 준비하고, 기안을 작성해 결재와 의결을 거친 뒤 지출결의·지급·전표까지 연결하는 흐름을 이해하도록 돕는다.

운영 주소: https://dbapt-erp.vercel.app/

## 화면 구성

- 왼쪽 사이드바: 대시보드, 기안·결재, 회계/자금, 조합원 등 업무 모듈로 이동한다.
- 상세 메뉴: 선택한 모듈의 세부 기능을 표시한다. 현재 페이지는 파란 배경으로 구분된다.
- 퀵메뉴: 조합원 등록, 은행거래 업로드, 지출결의 작성, 지급대기 등 자주 쓰는 기능으로 이동한다.
- 본문 카드와 표: 현재 상태, 처리할 업무, 금액과 최근 변경사항을 보여준다.

## 10분 빠른 시작

1. `/basic-info`에서 거래처, 계정과목, 은행통장과 카드를 확인한다.
2. `/basic-info/approval`에서 예산, 결재선, 의결규칙과 소액기준을 확인한다.
3. `/approval/new`에서 일반기안 또는 지출품의를 작성한다.
4. 결재선을 확인한 뒤 제출한다.
5. `/approval`에서 결재·의결·집행 상태를 각각 확인한다.
6. 승인과 필요한 의결이 끝나면 기안 상세에서 지출결의서를 생성한다.
7. `/finance/approval-inbox`에서 지출결의를 승인하고 `/finance/payment-waiting`에서 지급한다.
8. `/finance/payment-completed`와 `/finance`에서 지급 결과와 전표를 확인한다.

## 안전하게 사용하는 원칙

- 결재 완료, 회의 의결, 지출결의 승인, 실제 지급, 전표 생성은 서로 다른 단계다.
- 예산 외 지출이나 의결이 필요한 문서는 필요한 절차가 끝날 때까지 집행하지 않는다.
- 삭제 대신 회수·취소·정정을 사용해 이력을 남긴다.
- 첨부파일에는 개인정보와 계좌정보가 포함될 수 있으므로 필요한 담당자만 열람한다.
