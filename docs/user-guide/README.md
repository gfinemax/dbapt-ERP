# 대방동지역주택조합 ERP 사용설명서

이 폴더는 프로그램 변경에 맞춰 계속 갱신하는 사용설명서의 **기준 원본(Single Source of Truth)**이다. 화면 전체 캡처를 반복하지 않고 실제 경로, 업무 순서, 완료 기준을 중심으로 관리한다. 사용자가 읽고 공유하는 최종 결과물은 이 Markdown 원본을 통합한 Google Docs 문서로 배포한다.

## 문서 운영 방식

- 기준 원본: 이 폴더의 기능별 Markdown 문서
- 최종 결과물: Google Docs 통합 사용설명서
- 기능 구현 시: 관련 Markdown 문서와 `CHANGELOG.md`를 함께 수정
- 배포 시: 전체 Markdown 원본을 통합해 기존 Google Docs 문서를 갱신
- Word/PDF: 교육, 인쇄 또는 별도 보관이 필요할 때만 Google Docs 기준으로 생성
- 내용이 다를 때: Google Docs를 직접 따로 수정하지 않고 Markdown 원본을 먼저 바로잡은 뒤 다시 반영

## 문서 유지 원칙

- 화면 경로와 버튼명은 운영 프로그램의 실제 명칭을 사용한다.
- 스크린샷은 메뉴 진입, 복잡한 입력 화면, 정상 완료 화면처럼 꼭 필요한 장면만 사용한다.
- 기능 변경 시 관련 장과 `CHANGELOG.md`를 함께 수정한다.
- Google Docs는 배포본으로 취급하며, 내용의 기준은 항상 이 폴더의 Markdown 원본으로 한다.
- 정식 배포판을 만들 때 현재 운영 커밋과 최종 수정일을 표지에 기록한다.
- 문서에 없는 기능이나 비활성 메뉴는 사용할 수 있는 기능으로 안내하지 않는다.
