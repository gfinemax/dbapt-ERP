# 8. 문제 해결

## 문서가 목록에 보이지 않을 때

- 기안 목록의 현재 탭을 확인하고 `전체 문서`로 전환한다.
- 작성중, 진행중, 반려·보완 또는 회수·취소 탭을 확인한다.
- 브라우저를 새로고침하고 다시 조회한다.

## 지출결의서 생성 버튼이 보이지 않을 때

- 내부결재가 최종 승인됐는지 확인한다.
- 의결이 필요한 문서는 의결상태가 승인인지 확인한다.
- 계약기안의 분할지급 일정이 있으면 각 지급 일정에서 생성한다.
- 이미 지출결의서가 연결되어 있는지 확인한다.

## 예산이 부족하다고 표시될 때

- 편성예산, 실제 집행액과 다른 승인 기안의 집행예정액을 확인한다.
- 예산 항목이나 금액을 잘못 선택하지 않았는지 확인한다.
- 예산 외 지출이면 필요한 예산변경과 의결을 먼저 진행한다.

## 세부항목 합계 오류

각 행의 공급가액과 부가세 합계를 더한 값이 기안 총액과 정확히 같은지 확인한다. 원 단위로 입력하고 소수점은 사용하지 않는다.

## 첨부파일을 열 수 없을 때

- 첨부파일 열기 주소는 보안을 위해 짧은 시간만 유효하다. 상세 화면을 새로고침하고 다시 `열기`를 누른다.
- 업로드 가능한 파일 크기와 형식인지 확인한다.

## 페이지를 불러오지 못했을 때

1. `다시 시도`를 누른다.
2. 같은 문제가 반복되면 현재 경로, 발생 시각, 문서번호와 오류 화면을 기록한다.
3. 저장 버튼을 반복해서 누르지 말고 관리자에게 기록을 전달한다.

## 문의할 때 함께 전달할 정보

- 발생한 화면의 경로
- 문서번호 또는 거래처명
- 수행한 작업 순서
- 오류 메시지
- 발생 시각
- 개인정보를 가린 화면 캡처
