# 4. 회계·지급·전표 튜토리얼

## 전체 흐름

기안 승인 및 의결 완료 → 지출결의서 생성 → 지출결의 승인 → 지급대기 → 지급완료 → 지출전표 확인

## 튜토리얼 1: 지출결의서 작성·검토

경로: `/finance/expense-resolutions`

1. 기안에서 자동 생성하거나 `지출결의 작성` 퀵메뉴를 사용한다.
2. 제목, 지출 사유, 거래처, 프로젝트, 계정과목과 지급예정일을 확인한다.
3. 지급대상, 지급방법, 은행·계좌와 금액을 확인한다.
4. 증빙파일을 첨부하고 공급가액·부가세·총액을 대조한다.
5. 관련 기안번호와 계약·회의 정보가 올바른지 확인한다.
6. 임시저장 후 결재를 요청한다.

## 튜토리얼 2: 지출결의 승인

경로: `/finance/approval-inbox`

1. 결재함에서 결재대기 문서를 찾는다.
2. 상세를 열어 예산, 지급대상, 증빙과 공통 결재선 `담당자 장현제 → 사무국장 오학동 → 조합장 안동연`을 확인한다.
3. 승인하거나 반려 사유를 입력한다.
4. 최종 승인된 문서는 지급대기로 이동한다.

## 튜토리얼 3: 실제 지급

경로: `/finance/payment-waiting`

1. 지급대기 목록에서 지급일과 금액을 확인한다.
2. 상세에서 계좌번호, 예금주, 은행과 증빙을 다시 확인한다.
3. `지급처리`를 눌러 실제 지급 정보를 등록한다.
4. 지급하지 못할 사유가 있으면 `보류`하고 사유를 기록한다.
5. 지급 후 `/finance/payment-completed`에서 지급완료 상태와 전표 생성 여부를 확인한다.

## 튜토리얼 4: 전표와 은행거래 확인

1. `/finance`에서 수입·지출 전표를 조회한다.
2. 문서번호, 거래처, 계정과목, 차변·대변과 금액을 확인한다.
3. `/finance/bank-transactions`에서 은행거래를 업로드하거나 조회한다.
4. 은행거래와 전표가 올바르게 연결됐는지 확인한다.
5. 기존 지출결의나 전표는 관련 기안이 없어도 정상 문서로 관리한다.

## 증빙 OCR 사용 시 주의

- OCR 결과는 입력 보조값이므로 사업자명, 사업자번호, 공급가액과 부가세를 원본 증빙과 대조한다.
- 사용내용·거래처·OCR 품목에서 구체적인 분류 단어가 확인되면 지출 세부항목과 연결 예산이 자동 설정된다. 직접 선택한 세부항목은 자동 추천이 바꾸지 않는다.
- `(주)`와 같은 법인 표기는 실제 증빙의 공식 상호를 따른다.
- 인식이 불명확한 값은 자동 결과를 그대로 확정하지 말고 직접 수정한다.

## 예산 내 간편지출과 영수증 없는 지출

경로: `/finance/quick-expenses`, `/finance/expenses`, `/finance/reimbursements`

1. 승인된 월 예산 안의 통상적인 소모품·인쇄·수선·교통·통신비는 `간편지출`로 등록한다. 계약, 용역, 토지, 환불, 차입·상환, 예산 외 지출은 정식 지출결의를 사용한다.
2. 법인카드 지출은 카드 거래를 연결하고 실제 사용일, 거래처, 사용내용, 예산항목을 입력한다. 연결된 카드 거래와 영수증은 같은 비용의 원본이므로 중복 집계하지 않는다.
3. 영수증이 있으면 영수증 파일을 첨부한다. OCR 결과는 거래처·품목 입력을 돕지만 금액과 지급 원본을 자동 변경하지 않는다.
4. 영수증이 없으면 주문내역, 카드 승인내역, 계좌이체 확인증, 거래명세서, 물품 사진 등의 대체증빙과 미첨부 사유를 등록한다. 다른 승인자가 `대체증빙 승인`을 완료하기 전에는 정상 증빙 처리하지 않는다.
5. 개인카드·개인계좌 이체·현금으로 먼저 지출한 비용은 `개인 지출 정산`에서 신청한다. `영수증으로 정산`을 누르거나 드롭존에 파일을 놓으면 OCR이 사용일·금액·사용처·사용내용과 등록된 예산항목을 자동으로 채운다. 증빙에서 실제 품목을 확인하지 못한 경우에는 임의의 사용내용을 만들지 않으므로 직접 입력한다. OCR 결과는 초안이므로 모든 값을 수정할 수 있고, 사용자가 직접 고친 값은 다시 덮어쓰지 않는다. 영수증을 분실했거나 발급받지 못한 경우에는 `영수증 없음·예외 접수`에서 대체증빙과 미첨부 사유를 등록한다. 신청 목록은 기본적으로 사용월과 관계없는 `처리 중 전체`를 보여주며, 선택한 `월 사용분`과 그 달의 `완료·종료` 내역을 따로 확인할 수 있다. 신청 후에는 목록의 `상세 보기`에서 신청 내용과 증빙 원본을 한 화면에서 비교하고, 심사 중인 건은 거래처·사용내용을 수정 사유와 함께 바로잡을 수 있다. PDF 증빙은 한 번에 한 페이지만 크게 표시하고 여러 페이지 문서만 페이지 이동 버튼을 제공한다.
6. 이미 등록한 개인 선지출을 정산할 때는 `기존 지출 연결`을 선택한다. 저장된 값과 증빙을 재사용하고 새 증빙을 첨부한 경우에만 교체한다. 사용일은 실제 비용 귀속일로, 신청·승인·지급일은 각각 실제 처리일로 보존한다.
7. 같은 예산항목과 같은 귀속월의 미정리 원본이 있거나 월·연 예산을 초과하면 간편처리를 중단하고 원본 배정 또는 정식 지출결의를 진행한다. 다른 예산이나 다른 월의 미정리 건은 해당 지출을 막지 않는다.

관리자는 `/finance/expense-settings`의 `예산 내 간편지출 허용 예산항목`에서 정확한 예산항목명을 관리한다. 허용 목록에 없는 항목은 금액이 작아도 정식 지출결의 대상으로 안내된다.

## 퀵메뉴와 운영 준비 점검

1. 왼쪽 퀵메뉴의 톱니바퀴에서 자주 쓰는 메뉴를 추가·제거하고 순서를 바꾼다.
2. 로그인한 사용자의 설정은 같은 조합 계정으로 접속한 다른 브라우저에도 적용된다. 로그인 전에는 현재 브라우저에만 저장된다.
3. 다른 화면에서 먼저 설정을 바꾼 경우 기존 화면이 새 설정을 덮어쓰지 않는다. 새로고침 후 다시 저장한다.
4. 기본값은 `지출 등록·신청`, `법인카드 간편처리`, `지출결의 작성`, `개인 선지출 정산`, `지급대기`, `사업비 신탁 요청`, `월 운영비 정산`, `은행거래 업로드` 순서다. 기존에 저장한 개인 설정은 임의로 덮어쓰지 않는다.
5. 퀵메뉴의 숫자 배지는 해당 화면에서 이어서 처리할 실제 원본 수다. 0건은 표시하지 않으며 새 문서를 만드는 메뉴에는 대기 건수를 붙이지 않는다.
6. `환급관리`, `분담금 수납처리`, `증빙 보완`, `전체 지출` 등은 톱니바퀴에서 선택 메뉴로 추가할 수 있다.
7. `회계/자금 → 전표·증빙관리 → 설정 → 운영 준비 점검`에서 담당 역할, 확인 완료 신탁계약, 월 운영비 기준과 해당 연도 예산을 확인한다.
8. 처리 대기의 숫자는 오류 건수가 아니다. 카드 연결, 증빙 보완, 지출결의 전환, 개인 선지출 지급, 선지급·운영비 정산 등 담당자가 이어서 처리할 원본 수다.

## 사이드 메뉴 대기 배지와 기존 자료 정리

1. 로그인한 회계·자금 담당자에게만 사이드 메뉴의 대기 배지가 표시된다. 0건은 표시하지 않는다.
2. 배지는 지출결의 전환, 처리경로 미분류, 증빙 보완, 개인 선지출 지급, 선지급·운영비 정산처럼 원본에서 확인된 현재 건수다.
3. `설정 → 기존 자료 정리`에서 카드 연결, 증빙 보완, 결의 전환, 예산 귀속, 처리경로 확인 항목을 함께 조회한다.
4. 같은 원본에 서로 다른 확인 사유가 있으면 여러 분류에 표시될 수 있다. 따라서 분류별 건수의 합을 회계상 지출 건수나 금액으로 사용하지 않는다.

## 분담금 수납과 환급

1. `분담금 수납관리`에서 외부 조합원 원장의 고유 ID, 부과 코드·회차와 부과액을 등록한다. 여러 건은 `CSV 양식 받기`로 양식을 내려받아 UTF-8 CSV를 미리보기하고, 행별 신규·수정·오류를 확인한 뒤 적용한다. 미리보기는 취소해도 원본 해시와 판정 행이 이력에 남으며, 과거 검토 결과를 다시 열거나 결과 CSV로 내려받을 수 있다. 이름과 조합원번호는 확인용 스냅샷이며 자동 연결 키가 아니다.
2. 업로드된 실제 입금을 선택해 부과 원본에 부분 또는 전액 배분한다. 한 입금의 배분 합계는 실제 입금액을, 한 부과의 수납 합계는 부과액을 넘을 수 없다.
3. 잘못 만든 부과 원본은 유효한 수납 배분이 없을 때만 사유와 함께 취소하고, 잘못 배분한 수납도 삭제하지 않고 취소 이력을 남긴다. 환급 결정이나 지급 이력이 연결된 수납 배분은 취소할 수 없다.
4. 환급은 원수납 배분에서 작성하고, 작성자와 다른 담당자가 승인한 뒤 승인액과 같은 실제 출금을 연결해야 완료된다. 일부만 환급한 경우에는 원수납액에서 이미 결정한 환급액을 뺀 잔액 범위에서 후속 부분 환급을 만들 수 있으며, 검토 중인 환급안은 동시에 하나만 둔다.
5. 수납·환급 대기 건수는 사이드 메뉴와 `운영 준비 점검`에서 확인한다.

## 통합 월 마감 점검

1. `월 마감`에서 점검월을 선택하면 지출결의, 회계일, 계좌거래, 전표, 예산, 선지급, 운영비, 사업비 신탁, 개인 선지출, 수납과 환급을 함께 확인한다.
2. 표시된 숫자는 금액이 아니라 처리할 원본 수다. 각 항목의 링크에서 원본을 정리한 뒤 다시 조회한다.
3. 이 화면은 마감 준비 점검이다. 회계기간 잠금·재개방은 조합의 회계정책과 권한이 확정되기 전까지 실행하지 않는다.
4. `증빙자료 관리`의 원본 종류에서 간편지출 영수증도 직접 조회하고 다운로드할 수 있다.
5. 정리센터는 원본을 자동 수정·삭제·숨김 처리하지 않는다. 각 항목의 해결 화면으로 이동해 증빙과 근거를 확인한 뒤 기존 승인·정산 절차에 따라 처리한다.
