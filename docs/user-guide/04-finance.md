# 4. 회계·지급·전표 튜토리얼

## 전체 흐름

기안 승인 및 의결 완료 → 지출결의서 생성 → 지출결의 승인 → 지급대기 → 지급완료 → 지출전표 확인

## 튜토리얼 1: 지출결의서 작성·검토

경로: `/finance/expense-resolutions`

1. 기안에서 자동 생성하거나 `지출결의 작성` 퀵메뉴를 사용한다.
2. 제목, 지출 사유, 거래처, 프로젝트, 계정과목과 지급예정일을 확인한다.
3. 지급대상, 지급방법, 은행·계좌와 금액을 확인한다.
4. 증빙파일을 첨부하고 공급가액·부가세·총액을 대조한다.
5. 관련 기안번호와 계약·회의 정보가 올바른지 확인한다.
6. 임시저장 후 결재를 요청한다.

## 튜토리얼 2: 지출결의 승인

경로: `/finance/approval-inbox`

1. 결재함에서 결재대기 문서를 찾는다.
2. 상세를 열어 예산, 지급대상, 증빙과 공통 결재선 `담당자 장현제 → 사무국장 오학동 → 조합장 안동연`을 확인한다.
3. 승인하거나 반려 사유를 입력한다.
4. 최종 승인된 문서는 지급대기로 이동한다.

## 튜토리얼 3: 실제 지급

경로: `/finance/payment-waiting`

1. 지급대기 목록에서 지급일과 금액을 확인한다.
2. 상세에서 계좌번호, 예금주, 은행과 증빙을 다시 확인한다.
3. `지급처리`를 눌러 실제 지급 정보를 등록한다.
4. 지급하지 못할 사유가 있으면 `보류`하고 사유를 기록한다.
5. 지급 후 `/finance/payment-completed`에서 지급완료 상태와 전표 생성 여부를 확인한다.

## 튜토리얼 4: 전표와 은행거래 확인

1. `/finance`에서 수입·지출 전표를 조회한다.
2. 문서번호, 거래처, 계정과목, 차변·대변과 금액을 확인한다.
3. `/finance/bank-transactions`에서 은행거래를 업로드하거나 조회한다.
4. 은행거래와 전표가 올바르게 연결됐는지 확인한다.
5. 기존 지출결의나 전표는 관련 기안이 없어도 정상 문서로 관리한다.

## 증빙 OCR 사용 시 주의

- OCR 결과는 입력 보조값이므로 사업자명, 사업자번호, 공급가액과 부가세를 원본 증빙과 대조한다.
- `(주)`와 같은 법인 표기는 실제 증빙의 공식 상호를 따른다.
- 인식이 불명확한 값은 자동 결과를 그대로 확정하지 말고 직접 수정한다.

## 예산 내 간편지출과 영수증 없는 지출

경로: `/finance/quick-expenses`, `/finance/expenses`, `/finance/reimbursements`

1. 승인된 월 예산 안의 통상적인 소모품·인쇄·수선·교통·통신비는 `간편지출`로 등록한다. 계약, 용역, 토지, 환불, 차입·상환, 예산 외 지출은 정식 지출결의를 사용한다.
2. 법인카드 지출은 카드 거래를 연결하고 실제 사용일, 거래처, 사용내용, 예산항목을 입력한다. 연결된 카드 거래와 영수증은 같은 비용의 원본이므로 중복 집계하지 않는다.
3. 영수증이 있으면 영수증 파일을 첨부한다. OCR 결과는 거래처·품목 입력을 돕지만 금액과 지급 원본을 자동 변경하지 않는다.
4. 영수증이 없으면 주문내역, 카드 승인내역, 계좌이체 확인증, 거래명세서, 물품 사진 등의 대체증빙과 미첨부 사유를 등록한다. 다른 승인자가 `대체증빙 승인`을 완료하기 전에는 정상 증빙 처리하지 않는다.
5. 개인카드·개인계좌 이체·현금으로 먼저 지출한 비용은 `개인 지출 정산`에서 신청한다. 사용일은 실제 비용 귀속일로, 신청·승인·지급일은 각각 실제 처리일로 보존한다.
6. 같은 예산항목과 같은 귀속월의 미정리 원본이 있거나 월·연 예산을 초과하면 간편처리를 중단하고 원본 배정 또는 정식 지출결의를 진행한다. 다른 예산이나 다른 월의 미정리 건은 해당 지출을 막지 않는다.

관리자는 `/finance/expense-settings`의 `예산 내 간편지출 허용 예산항목`에서 정확한 예산항목명을 관리한다. 허용 목록에 없는 항목은 금액이 작아도 정식 지출결의 대상으로 안내된다.
