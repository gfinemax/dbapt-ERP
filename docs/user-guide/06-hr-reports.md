# 6. 인사·급여와 보고서

## 인사·급여

경로: `/hr-payroll`

1. `사원정보등록`에서 직원 기본정보를 확인하거나 입력창을 연다.
2. `급여입력`에서 지급항목과 공제항목을 입력한다.
3. 지급총액, 공제총액과 실지급액을 확인한다.
4. `급여대장`에서 월별 급여 결과를 검토한다.
5. 급여 전표가 필요한 경우 회계 흐름과 연결 여부를 확인한다.

## 보고서

경로: `/finance/reports`

- 보고서 목록: 필수 출력 문서와 자동 생성 보고서를 확인한다.
- 실적보고서: 기간별 사업 실적을 확인한다.
- 자금입출금명세서: 월별 수입·지출과 운영비 세부내역을 확인한다.
- 운영비 예산: 예산 항목별 편성액과 집행 결과를 확인한다.

보고서를 외부 공개하거나 회의자료로 사용할 때는 조회기간, 단위, 작성기준일과 미확정 거래 여부를 먼저 확인한다.
